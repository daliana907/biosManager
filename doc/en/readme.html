BIOS / UEFI Manager for NVDA

Author: Daliana | Version 1.7 | Compatibility: NVDA 2023.1 or later

This add-on allows blind and visually impaired users to view and modify UEFI firmware settings directly from Windows using NVDA.

Legacy BIOS vs. UEFI

It is important to distinguish between legacy BIOS and modern UEFI firmware:

  • Legacy BIOS cannot be controlled or configured from the operating system once booted.
  • Modern UEFI firmware allows communication and configuration through the Windows WMI interface.
  • Therefore, this add-on works exclusively on systems with native UEFI firmware. It will not work on legacy BIOS machines or when Compatibility Support Module (CSM) legacy emulation is active.

Supported Computers

  • Lenovo business systems: ThinkPad laptops, ThinkCentre desktops, and ThinkStation workstations.
  • On custom-built PCs or machines without vendor WMI support, the add-on will safely report that no supported interface was found.
Security & Responsible Use:
  • Boot order: Altering boot devices or disabling drives can prevent Windows from starting normally.
  • Security & Virtualization: Modifying options like Secure Boot, TPM, passwords, or virtualization (VT-x / AMD-V) can impact drive encryption (BitLocker) or virtual machine support. Only modify settings you understand.
  • Secure screen blocking: The add-on blocks execution on secure Windows desktops to prevent unauthorized high-privilege access.

Tools Menu Options & Shortcuts

The add-on does not assign any default keyboard shortcut to avoid conflicting with NVDA's core commands (such as NVDA+Shift+B for battery status). All actions are available from the menu and can be assigned custom gestures:

  • BIOS / UEFI Settings...: Opens the main configuration dialog.
  • Reboot to UEFI / BIOS settings...: Reboots the machine directly into UEFI firmware setup.
  • Check conflicts with other add-ons...: Diagnoses duplicate shortcuts or add-on collisions.
  • Documentation: Opens this user guide via NVDA's official documentation API.
  • Assigning gestures: You can assign custom shortcuts via NVDA Menu > Preferences > Input Gestures under the "BIOS and UEFI Manager" category.

Using the Settings Dialog

  1. Open the dialog from the Tools menu. Wait a few moments for options to load.
  2. Type in the search box and press Enter or click the Filter button. Click Clear to reset.
  3. On the right panel, edit the setting based on its type (dropdowns, dynamic date editor, time, signed 32-bit integer spin control, or text).
  4. In the boot order list, select a device and press Alt + Up Arrow or Alt + Down Arrow (or use the Move up and Move down buttons) to reorder.
  5. Click the Add to pending changes button.
  6. Click OK (or press Enter) and accept the Windows UAC confirmation to write changes to UEFI, or Cancel (or Escape) to discard changes in memory and exit.

What's new in 1.7 (12 September 2026)

Security and Compatibility

  • Prevents loading in NVDA secure mode to eliminate privilege escalation risks.
  • Removed default keyboard shortcut to avoid overriding NVDA's native battery status command.
  • Added a Tools menu option to reboot directly into UEFI firmware setup.
  • Uses NVDA's official API (openDocumentation) to open documentation according to the active language.
  • Conflict detection regex now uses word boundary matching to eliminate false positives on words like "cambios".
  • Dynamic month and leap-year validation for BIOS date settings (1970-2037).
  • Signed 32-bit integer range (-2147483648 to 2147483647) for numeric spin controls.
  • Settings with available options are correctly treated as dropdowns even when their current value is empty.
  • Canceling the dialog no longer triggers unnecessary WMI calls.

What's new in 1.6 (8 September 2026)

Fixed

  • BIOS changes were never applied: the command sent to Windows was malformed.
  • The file with the BIOS answer was left in a folder NVDA could not always read, and the operation appeared to fail for no reason.
  • Applying a change was assumed to work without checking. The value is now read back and you are told whether the BIOS accepted or rejected it.
  • Saving to the BIOS froze NVDA until it finished. It now runs in the background.
  • Closing the window with a typed but unapplied change lost it silently. It now warns you.
  • Boot order was edited with one dropdown per position, so a device could be repeated and another omitted with no warning.
  • BIOS queries could wait forever if the machine did not answer or nobody responded to the permission prompt.

Internal changes

  • Boot order is now edited in a single list reordered with Alt and the arrow keys, and only what actually moved is summarised on apply.
  • The settings editor separates deciding which editor a value needs from building it, and that decision has its own tests.
  • Removed about 119 lines of code that were no longer used.
  • Fixed two security issues: a temporary file with a predictable name, and values sent to Windows without escaping.
  • Added 52 automatic checks that run on their own on GitHub with every change.

The full history of every version is in the CHANGELOG.md file of the add-on repository.
