BIOS / UEFI Manager for NVDA

Author: Daliana | Version 1.5 | Compatibility: NVDA 2023.1 or later

This add-on allows blind and visually impaired users to view and modify BIOS/UEFI firmware settings directly from Windows using NVDA.

Supported Computers

  • Lenovo business systems: ThinkPad laptops, ThinkCentre desktops, and ThinkStation workstations.
  • On custom-built PCs or machines without vendor WMI support, the add-on will safely report that no supported interface was found.

How to use

  1. Press NVDA + N, go to Tools > BIOS and UEFI Manager > BIOS / UEFI Settings (or press NVDA + Shift + B directly).
  2. Wait a few seconds for settings to load. Browse the list on the left or use the search box.
  3. On the right side, adjust the setting with arrow keys or type as needed.
  4. Click Add to pending changes.
  5. When done, click OK and accept the Windows UAC confirmation. Changes will apply on next restart.
Safety: Communicates via official Lenovo WMI interfaces. Motherboard firmware verifies every setting and rejects invalid entries, keeping your machine safe.

Tools Menu Options

  • BIOS / UEFI Settings: Opens the main configuration dialog.
  • Check conflicts with other add-ons: Diagnoses duplicate shortcuts or add-on collisions.
  • Documentation: Opens this user guide.
